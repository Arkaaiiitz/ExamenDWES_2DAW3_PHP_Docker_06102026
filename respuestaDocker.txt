// Responde a la pregunta sobre docker del enunciado
/*Explica lo mejor posible qué hace cada opción del siguiente comando de docker:
docker run -d --name mi_web -p 8080:80 nginx*/

La documentación principal de docker explica que docker run crea y 
ejecuta un contenedor y permite ejecutarlo en segundo plano con -d.
Se le asigna un nombre con --name y publica puertos con -p.

Por otro lado, la documentación de Docker (Publishing and exposing ports)
explica que el formato 8080:80 establece una conexión entre el puerto 8080 del equipo 
host y el puerto 80 del contenedor permitiendo acceder al contenedor.

Por último, nginx es la imagen oficial de Nginx disponible en Docker Hub.
